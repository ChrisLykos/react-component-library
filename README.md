# React Component Library

A reusable React component library built with **React**, **TypeScript**, and **Vite**.

## Status

Currently in the **foundation / setup phase**.

Components, testing, Storybook, and design system foundations will be added incrementally.

## Tech Stack

- React
- TypeScript
- Vite
- ESLint
- Prettier

## Setup

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run format
npm run format:check
```

## Goal

Build a small, accessible, tested, and well-documented component library while learning professional React library architecture.
